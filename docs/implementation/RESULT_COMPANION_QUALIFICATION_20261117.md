# Saved-result companion qualification — November 17, 2026

This default-off increment adds **Understand this result** to a successful,
durably saved result. It describes one selected field, preserves exact numeric
values and saved-row references, and offers editable guided follow-ups. Applying
a draft never sends it. The existing `COMPANION_ENABLED` flag remains false by
default. See [the closed contract](RESULT_COMPANION_CONTRACT.md).

It uses current owner/session/grant/history/job authorization and the saved
result, with authorization repeated before publication. The caller supplies
only the canonical request UUID and selected column index. The route has its
own 8 KiB raw-body bound, strict JSON decoding, existing committed admission,
two-second cooperative deadline and 32 KiB complete-response bound.

No model, analytical query, new persistence, company memory, approval or executor
is added. Units, filters, aggregation and source freshness remain unknown rather
than inferred from labels. Generation time is displayed separately from freshness.
Legacy results without metadata receive an explicitly limited brief. Malformed
current metadata and unsafe integral numbers without exact sidecars fail closed.

## Limits and release status

The result-companion browser journey uses mocked HTTP. Backend API tests use
the real application and disposable database fixtures; this combination is not
a browser-to-real-backend or deployed HTTP/TLS acceptance claim. Out-of-band
callback probes for target/draft replacement are labelled accordingly. The
failed optional chunk remains contained, but a rejected `React.lazy` import is
cached for the document; same-page redownload is not promised.

Follow-ups reuse the existing bounded guided-question serializer. An arbitrarily
old selected result is not guaranteed to retain its original SQL/filters in the
existing eight-question/two-SQL analysis context. The interface leaves missing
scope explicit and requires the user to review the draft and separately Send.

This evidence establishes a local source increment. It does not establish model
training, autonomous planning, continuously learning memory, bank integration,
bank compliance, live penetration testing, production recovery or deployed
acceptance. Dependency-security, exact-head/combined-main CI and P11–P13 release
gates remain separate. No production application/configuration/schema/data/model
was changed by qualification; isolated source stages and untagged QA image caches
are retained separately.
